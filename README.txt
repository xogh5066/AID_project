AID Data Lab — URL 배포용

이 패키지는 배포 준비 파일입니다. 실제 사이트 URL은 https://aid-project.onrender.com 에서 가능합니다.

1. AI_API_URL: 사용하는 서비스의 전체 Chat Completions HTTPS 주소
   AI_API_KEY: 본인이 발급한 비밀 키
   AI_MODEL: 계정에 허용된 정확한 모델 식별자
   SESSION_SECRET: 추측 불가능한 임의의 긴 문자열(32자 이상 권장)
   ACCESS_CODE: 심사위원에게만 공유할 입장 코드(12자 이상 필수)
   DAILY_AI_LIMIT: 50 (서버 전체 하루 AI 요청 횟수 상한)
2. 입장 코드 → 가상 데이터 → 모든 분석 계산 → 세 답안 작성 → 전송 동의 → 피드백.
   정상 답안과 틀린 답안을 각각 제출해 피드백 차이를 확인하세요.
3. 학생에게는 사이트 주소와 입장 코드만 전달합니다.

유의사항
- HTTPS 필수. API 키는 서버에서만 사용하며 웹 페이지에는 넣지 않습니다.
- 입장 코드는 보조 통제입니다. 로그인 계정이나 강력한 사용자별 제한을 대신하지 않습니다.
- 세션당 하루 10회, 전체 하루 기본 50회. 실패한 AI 시도도 횟수에 포함됩니다.
- 날짜 기준 UTC. 서버 재시작 시 횟수 초기화. 쿠키를 지우면 세션 한도는 초기화됩니다.
- 호스팅 플랫폼의 재시작/확장에 무관한 엄격한 예산 통제가 아닙니다.
  AI 서비스 자체의 이용 한도/예산도 반드시 설정하세요.
- 실제 학생 대상 장기 운영에는 DB/Redis 기반 제한, 계정 인증, 개인정보 정책이 추가로 필요합니다.
- 원본 CSV 행은 보내지 않으나 요약통계·분석 결과·주관식 답안은 외부 AI로 전송됩니다.
  가상 데이터로 시연하고 개인정보와 민감정보를 입력하지 마세요.
- 입력한 계산 결과는 브라우저에서 전달된 값으로 서버가 원본 데이터를 재검산하지 않습니다.
  AI 참고 피드백이지 시험 성적 산출/부정행위 검증 도구가 아닙니다.
- 앱은 데이터와 답안을 DB에 저장하지 않습니다. 외부 AI/호스팅 서비스의 보관 정책은 별도입니다.
- PC용 .bat 대신 호스팅에서 gunicorn 시작 명령을 사용합니다.

검증 상태
Python 문법과 핵심 설정·요청 검사를 점검했습니다.
실제 호스팅 배포, 브라우저 테스트, 실제 AI 호출은 수행하지 않았습니다.
오류 발생 시 API 키를 가리고 오류 메시지만 전달하세요.
