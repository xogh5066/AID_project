아직 불러온 데이터가 없습니다. 상단의 가상 데이터로 시작해 보세요.

시연 시나리오

학습 지원, 누구에게 필요할까?

가상 학생 60명의 학습 시간, 출석률, 사전 점수, 최종 점수를 분석하고 학습 지원에 필요한 근거를 제안합니다.

1
문제 발견

어떤 변수가 최종 점수와 함께 움직일까?

2
검증과 예측

회귀 모델로 예측하고 별도 평가 데이터로 오차를 확인합니다.

3
책임 있는 의사결정

상관과 인과를 구분하고 결과의 한계를 작성합니다.

샘플은 교육용으로 생성한 가상 자료이며 실제 학생·교육성과를 나타내지 않습니다.

데이터 미리보기 최대 12행

CSV를 불러오면 표시됩니다.

기술통계 · 데이터 품질

수치형 변수별 유효값, 평균, 표본 표준편차, 최솟값과 최댓값을 확인합니다.

데이터를 먼저 불러오세요.

두 변수의 관계 탐색

피어슨 상관계수 r을 계산합니다. 두 변수에 모두 값이 있는 행만 사용합니다.

|r| ≥ 0.7: 강한 관계, ≥ 0.3: 중간 관계라는 교육용 기준을 사용합니다. 상관은 원인을 입증하지 않으며, 비선형 관계와 이상치를 별도로 확인해야 합니다.

예측 실습

단순 선형회귀

완전한 값이 있는 행을 고정 시드로 섞어 80%는 학습, 20%는 평가에 사용합니다.

서로 다른 수치형 변수 2개를 선택하세요.

평가 MAE는 평균 절대 오차입니다. R²가 음수면 평가 집합의 평균으로 예측하는 기준보다 나쁩니다. 이 모델은 연습용이며 실제 학생 선발·평가에 사용하지 마세요.

통계적 추론 실습

평균의 95% 신뢰구간

표본 수가 30 이상인 경우 정규근사(z = 1.96)로 계산합니다.

무작위·독립 표본을 가정합니다. 같은 절차를 반복하면 구간의 약 95%가 모집단 평균을 포함한다는 의미입니다. 이 자료의 모집단 대표성이 보장되는 것은 아닙니다. n<30은 이 시연에서 계산하지 않습니다.

분석가의 의사결정 노트

목표: 학습 지원 방안을 제안하되, 데이터가 말할 수 없는 것까지 구분하세요.

AI 학습 피드백

로컬 AI 연결 설정 확인 중…

분석 근거 30점 · 인과·불확실성 30점 · 실행·한계·윤리 40점. 점수는 교육용 참고이며 공식 평가가 아닙니다.

상관분석 → 회귀 학습 → 새 값 예측 → 신뢰구간 계산을 완료한 뒤 세 문항을 작성하세요. AI가 계산 결과와 답안을 대조하여 수치 해석, 인과관계, 제안의 타당성을 평가합니다. 실패 시 가짜 피드백으로 대체하지 않습니다.
발표용 시연 순서 · 약 3분
  1. 가상 데이터 불러오기 → 데이터 구조 확인
  2. 학습시간과 최종점수 상관 계산
  3. 회귀 학습 → 새로운 학습시간으로 예측
  4. 신뢰구간 확인 → 인과관계 주의점 설명
  5. 미션 피드백 → 실습 결과 저장
이 시연의 기능과 실제 교육 효과는 다릅니다. 공모전 제출 시 실제 참여자 수, 사전·사후 평가, 학생 동의 및 개선 결과를 별도로 수집·검증하세요.


확장 실습 · 전처리 / 시각화 / 고급 모델
탐색 전처리는 현재 화면 자료에 적용합니다. 고급 모델은 데이터 누수를 줄이기 위해 업로드 원본에서 별도로 분할합니다. 빈 셀만 결측으로 처리합니다. ID·이름·학번은 설명변수에서 제외하세요.
